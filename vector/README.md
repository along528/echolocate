# CloudCrate Vector Service

A serverless Vector Database service built with **DuckDB** and **Cloud Run**, backed by **Google Cloud Storage**.

This service provides a read-only HTTP API to search for similar music tracks using vector embeddings (generated by MERT-v1-95M).

## Architecture

*   **Compute**: Google Cloud Run (Gen2 execution environment).
*   **Database**: DuckDB using the `vss` extension for HNSW vector indexing.
*   **Storage**: A GCS bucket (`cloud-crate-vector-db`) mounted as a filesystem volume at `/data`.
*   **API**: FastAPI (Python).

## Setup & Deployment

### 1. Prerequisites
*   Python 3.11+
*   Google Cloud SDK (`gcloud`) authenticated.
*   `venv` active with dependencies installed (`pip install -r requirements.txt`).

### 2. generate the Database
The database is static and generated locally before upload.

```bash
# Generates 'data/cloudcrate.duckdb' from 'data/embeddings.jsonl'
python ../audio_embedding/generate_db.py
```

### 3. Setup Infrastructure (Upload DB)
Creates the GCS bucket (if needed) and uploads the generated `.duckdb` file.

```bash
./setup_infra.sh
```

### 4. Deploy to Cloud Run
Deploys the container and mounts the GCS bucket.

```bash
./deploy.sh
```

## Usage

### endpoint: `GET /tracks`

List tracks with paging.

**Query Params:** `limit` (default 50), `offset` (default 0).

### endpoint: `GET /tracks/{id}/similar`

Find similar tracks by ID.

**Query Params:** `limit` (default 10).

### endpoint: `POST /interpolate`

Find the "sonic midpoint" between two tracks.

**Request:**
```json
{
  "track_id_1": "track_id_a",
  "track_id_2": "track_id_b",
  "limit": 10
}
```

### endpoint: `POST /search`

Finds the nearest neighbors for a given 768-dimensional vector.

**Request:**
```json
{
  "vector": [0.12, -0.05, ...],  // 768 floats
  "limit": 10
}
```

**Response:**
```json
[
  {
    "id": "crate/Artist/Title.mp3",
    "title": "Title",
    "artist": "Artist",
    "album": "Unknown",
    "relative_path": "crate/Artist/Title.mp3",
    "similarity": 0.95
  }
]
```
